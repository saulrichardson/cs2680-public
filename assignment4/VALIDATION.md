# Validation of the current repair harness

Use [test/teamharness/README.md](test/teamharness/README.md) for focused commands,
generated safety properties, reachable successful paths and mutation testing.
The scope of a check is the source, inputs, and environment actually exercised.

Local tests exercise saved requests, real processes, exact source replay,
continuation, completion and takeover. Live model outcomes, Linux qualification
and course deployment are separate evidence. No single process exit or review
opinion establishes correctness of a repair.
